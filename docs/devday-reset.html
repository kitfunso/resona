Product and scope

The user chose to keep Resona's wellness focus and accepted a private wellbeing check-in ending with one practical next step. Existing Resona has authenticated Breath, Motion and Heart flows. Today adds a self-contained, public reset journey, accessible at /reset.html, using the existing React and Vite workspaces.

Choose between reworking the sensor and account flows or adding a focused reset. Pick the reset: it gives a complete journey that judges can open immediately and finish without signing in, granting sensor access or entering personal details. The old app remains available at the root.

Success: a visitor chooses how they feel and what they need, completes or explicitly skips a guided minute, records their own response, and saves a useful next step. No diagnosis, inferred health score, employer report or claim that the session improved their wellbeing.

Personalisation is an explicit local rule table. No model runs in this feature. Codex's contribution is the new implementation, acceptance tests, review and demo preparation. No AI-generated advice claim will appear.

Journey and state

  1. Check in: choose energy (low, steady, busy) and intention (focus, unwind, step away). Neither is selected by default. Native fieldsets and radio inputs; continue disabled until both are chosen.
  2. Reset: a sixty-second visual breathing guide with comfortable, optional pacing. Start is explicit. Pause, resume, and finish early are always available. Tab hiding pauses the timer. Reduced-motion visitors receive the same textual guide with no scaling motion. Never instruct breath holding or forced inhalation.
  3. Reflect: choose more settled, about the same, or less settled. No response is inferred. An early finish is labelled as such. Going back must preserve only the current in-memory selections.
  4. Take away: show the actual before/after choices, completion status, and one concrete next step determined by the choices. Honest copy for unchanged or worse responses. Download a plain-text card, or restart and clear the session.

No server call, analytics, browser storage, sensor request, free-text health input, or background persistence. Reloading clears the check-in. Downloads occur only after the visitor clicks save. External font requests are already used by Resona; the feature remains usable on fallback fonts if those fail.

Acceptance details

  • Normal journey: choose busy + focus; start; finish sixty active seconds; choose same; result offers one focus action and reports the actual unchanged response.
  • Paused time does not count; resuming retains remaining time; hiding the tab pauses; reset completion cannot fire twice. A late interval callback computes from elapsed time rather than counting ticks.
  • Early finish never says a full minute was completed. Less-settled response shows neutral copy and suggests stopping rather than trying harder.
  • Invalid energy, intention or reflection values are rejected by the pure functions. Test every valid choice mapping and unknown values.
  • Downloading includes selected labels and the shown action; no hidden profile, random health score or old session values. Restart clears all choices.
  • At 320px, 768px and 1440px there is no horizontal overflow. Keyboard can complete the whole flow. Reduced-motion mode has no dial scaling.
  • The built /reset.html opens without an API or login. Root still builds. No check-in data is sent over the network or stored.
