# Codex analytics status

The `/api/codex-analysis` route is disabled and returns HTTP 503. It does not reserve the shared quota or contact OpenAI. The Pages app must show its local fallback without a Codex label. `codex-report.mjs` contains the intended scalar input validation and a fixed, nonclinical mapping from action codes to the existing report shape; it is not connected to a provider.

A synthetic request on 1 November 2026 to `POST /v1/agents/sessions` received HTTP 400 with `unknown_parameter` for `spend_control`. The [Python SDK reference](https://developers.openai.com/api/reference/python/resources/beta/subresources/agents/subresources/sessions/methods/create) lists a top-level session limit in US cents, while the [REST create reference](https://developers.openai.com/api/reference/resources/beta/subresources/agents/subresources/sessions/methods/create) does not list this field. No session ID or usage was returned. Do not remove this control to enable the route: a limit on the number of requests is not a per-session spending limit, and reported consumption is best effort.

The REST reference requires an input when using an environment of type `none` and permits an input array with zero items. Whether `input: []` creates an idle session has not been verified. Before submitting any readings, a future implementation must confirm the session is idle, durably register its ID and schedule cleanup. Keep the existing `resona-sensor-demo` Durable Object and its counter; a new Worker namespace would reset the effective cap. Do not log requests, outputs, credentials, or readings.

Agent session content is retained until deletion, with physical cleanup asynchronous. The [data controls](https://developers.openai.com/api/docs/guides/your-data) describe the retention of abuse-monitoring logs and the service's residency. Tell participants what will be sent and obtain their agreement before any future provider call. Durable cancellation and deletion retry after disconnect remains unimplemented; do not enable the provider until tested.
